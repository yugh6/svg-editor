# Lab1：SVG 命令行编辑器

实现范围以 `phase_cli_1.md` 第一阶段为准：六种内置图形、树结构编辑、SVG 读写、撤销与重做，不实现后续阶段的 box 插件。

## 架构方案（初稿）

- `domain/`：封装图形、几何、容器、文档树与结构不变量。
- `commands/`：一条用户命令对应一个命令对象；编辑命令可撤销。
- `application/`：当前文档、历史记录与执行事务；依赖 domain 和 IO 接口。
- `io/`：文件系统端口及 SVG XML 编解码。
- `cli/`：参数解析、命令分发和逐行交互。
- `main.ts`：装配具体依赖。

采用 Command、Composite 和 Memento：编辑在副本上执行，成功后一次性替换文档；保存前后快照作为一条命令的撤销单元。第一阶段优先保证失败原子性和层级恢复正确，接受每次编辑 O(n) 的快照成本。

按名字分派仅保留命令注册表与图形工厂注册表；两处均是后续插件化阶段的待重构点。叶子图形的移动、缩放、属性设置及显示通过多态实现，不在命令层按类型分支。
